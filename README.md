# シャープ比ポートフォリオリスク・リターン分析

複数資産の期待リターン・標準偏差・相関係数を入力してポートフォリオのシャープ比を計算し最適配分を分析するツール。

## 機能

- 最大5資産まで追加可能（資産名・期待リターン%・リスク%・配分%入力）
- ポートフォリオ全体のリターン・リスク・シャープ比を計算（相関係数は簡略化・ゼロ仮定）
- リスク-リターン散布図（各資産と現在ポートフォリオをSVGプロット）
- 配分スライダーで動的にシャープ比変化を確認
- 無リスク金利入力対応
- 資本市場線（CML）表示

## 技術仕様

- バニラJS / Tailwind CDN
- シャープ比計算: (Rp - Rf) / σp
- XSSガード: escHtml関数によるユーザー入力のサニタイズ
- レスポンシブ対応 / アクセシビリティ: aria-label付与済み
